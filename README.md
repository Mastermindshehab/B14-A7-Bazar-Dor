# বাজার দর (BazarDor)

**BazarDor** is a responsive product price comparison web application that helps users explore products, check prices, browse categories, and discover price trends in one place.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB

## Key Features

1. **Product Browsing:** Explore products and view their details.
2. **Category-Based Filtering:** Browse products by category and sort them according to available options.
3. **Price Trends:** Discover products with rising and falling prices.
4. **User Authentication:** Register and sign in securely using Better Auth.
5. **Responsive Design:** Enjoy a user-friendly experience across mobile, tablet, and desktop devices.
